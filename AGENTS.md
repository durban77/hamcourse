# Instructions for AI assistants

## Project context
- This repository contains beginner-level amateur radio course materials in Hungarian.
- Before editing, inspect the repository to learn its structure, formats, and conventions. Do not assume a particular directory layout or toolchain.
- Treat existing materials as the source of truth for established course scope and terminology.

## Language and style
- Write learner-facing content in clear, natural Hungarian unless the surrounding material uses another language.
- Preserve the existing tone, terminology, formatting, and level of detail.
- Explain technical terms when they first appear, and favor concise examples suitable for beginners.
- Keep slides brief and scannable. Put fuller explanations in speaker notes or companion documentation when the existing format supports them.

## Accuracy and safety
- Do not invent technical facts, citations, regulations, or exam requirements.
- For claims that may change—especially Hungarian regulations, licensing, frequency allocations, and operating requirements—verify against current authoritative sources. Include a link and access or publication date where appropriate.
- Make the jurisdiction and date clear when regulatory information is included.
- Present practical guidance responsibly, including applicable legal and equipment-safety considerations.

## Editing and validation
- Make focused changes; avoid unrelated rewrites, format conversions, or new dependencies.
- Preserve the source format and any existing slide, build, or documentation conventions.
- Check links and formatting where practical. Run only validation commands supported by the repository.
- If a request is ambiguous or a factual claim cannot be verified, flag the uncertainty rather than guessing.

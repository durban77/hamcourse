# Bemutatók (HAREC)

Ezek a bemutatók a HAREC (haladó, CEPT) fokozatú rádióamatőr vizsgára felkészítő
tanfolyam kivetítőjén használt vizuális anyagok. A cél: kevés szöveg, sok pont,
könnyen előadható tartalom — de a HAREC vizsga tárgyköreinek teljes (`B`-jelölésű)
mélységében.

Az anyag a 15/2013. (IX. 25.) NMHH rendelet 1. melléklete szerinti `B` (HAREC)
tárgyköröket fedi le, önállóan (az Alap fokozatú `/alapdiak` anyag ismerete nélkül
is követhető).
